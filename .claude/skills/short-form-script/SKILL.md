# Short-form script structure

Use this before cutting footage. It sets what the speaker says; `write-script` then
tests hook variants and `edit-video` handles the edit.

## Shape (target 45-90 s, don't pad)

1. **Hook** (1-2 sentences) — state the subject in sentence one, then raise curiosity.
2. **Lock-in** (2-4 sentences) — make the rest feel worth watching. Use one of: teased proof,
   teased transformation, clear contrast with common belief, a named "magic box" method,
   objection handling, or doubling down on the hook.
3. **Body block 1** (3-5 sentences) — at least one contrarian or non-obvious insight, backed by a fact, example or reason.
4. **Rehook 1** (1 sentence) — open a new curiosity loop to reset attention (viewers drift after about 20-25 s).
5. **Body block 2** (3-5 sentences) — a second non-obvious insight. Two hits of value keep people watching.
6. **Rehook 2** (1 sentence), then optional **Body block 3** (3-5 sentences).
7. **Closing** (optional, 1-2 sentences) — skip it when the CTA carries the ending.
8. **CTA** (1 sentence) — a value ramp tied to the topic (lead magnet is best). Use one on every video so conversions can be measured.

## Checks before filming
- Subject is in the first sentence. Every sentence either follows the last or clearly starts a new idea.
- Simple words. Cut fluff. If a sentence doesn't add curiosity, proof or payoff, delete it.
- Names, numbers and claims match the user's notes. Flag anything unverified rather than guessing.
- Count the spoken seconds (about 2.5 words per second) and check against the 15-90 s output spec in `REEL_PLAYBOOK.md`.

## Output
Return the script as labelled sections (Hook, Lock-in, Body 1, Rehook 1, Body 2, Rehook 2, CTA)
with an estimated runtime. Hand it to `write-script` for hook variants or to `edit-video` for the cut.
